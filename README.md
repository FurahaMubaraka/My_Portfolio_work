## Project Description
This project is a **multi-page personal portfolio website** developed using **pure HTML5**,
without any CSS or JavaScript, as required by the practical activity instructions.

---

## Website Pages
1. **Home** – Introduction and portfolio overview with profile image  
2. **About** – Personal background, education, work experience, and favorite quote  
3. **Services** – Services offered using lists and tables  
4. **Skills** – Technical and professional skills, HTML code examples, and progress elements  
5. **Media** – Image gallery, audio, video, and embedded content  
6. **Form** – Full HTML form with all input types  
7. **Contact** – Multiple contact methods, physical address, and Google Maps iframe
